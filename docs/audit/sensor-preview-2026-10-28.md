# Sensor presentation preview — 28 October 2026

The web page now starts in **Live + preview readings** mode. A persistent, keyboard-accessible control switches to **Live readings only**. Fresh received values take priority independently for pulse, oxygen and probe temperature. Unavailable values use bounded generated examples with a Preview label. Activity uses fresh received data when available, otherwise a generated steps/distance/calories/minutes example. Known generated activity sources retain their Preview label.

Dashboard, Vitals, Activity and Trends use a separate presentation hook. Example history appears only when the corresponding recorded history is empty and is labelled generated. Existing recorded history remains untouched. ECG shows a labelled generated animation separately from actual ADC, contact and clipping summaries; no diagnostic rhythm is invented. Reduced motion disables its animation.

The authenticated health store, firmware, ingestion APIs, reports, AI context and SOS worker were not changed. Preview objects never enter those stores or APIs. Further SOS development is paused; existing external delivery remains unconfigured. The completed video was not edited.

Validation: TypeScript and targeted ESLint passed; production build passed; 39 existing frontend tests passed. A local browser fixture confirmed real-value priority, missing-sensor previews, switching back to live-only data, preservation of actual ECG quality, reduced motion, no page exceptions, no API writes and no horizontal overflow at 320 and 1440 pixels. Evidence: `artifacts/sensor-preview-2026-10-28/`. Physical sensor testing remains deferred as requested.

Follow-up: the dashboard wellness ring initially remained blank because its score still came exclusively from the real health summary. The presentation hook now supplies a labelled display-only heuristic when no server score exists and preview mode is enabled. Both the dashboard and Wellness page use that value. Existing server scores, including zero, take priority; live-only mode removes the generated score. ECG is explicitly excluded from the example calculation. No score is written into the health store or sent to the server. TypeScript, lint, production build and all 42 frontend tests passed, including three score-isolation regressions. Browser checks and visual inspection confirmed the dashboard ring and Wellness page at desktop and mobile sizes. Evidence: `artifacts/wellness-preview-2026-10-28/`.
