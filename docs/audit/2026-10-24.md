# Project audit — 24 October 2026

This is the pre-remediation baseline, condensed on 25 October for readability. It records **36 findings: eight P1, 24 P2 and four P3**, plus 11 follow-ups. The source locations below refer to the audited revision; later refactors may have moved or removed them.

For current behavior, read the [feature guide](../FEATURES.md). For repairs and evidence, use the [status ledger](STATUS.md) and [remediation plan](PLAN.md).

## Baseline evidence

API/web builds passed, but the initial check had only three threshold tests, 16 frontend lint errors and a 781.24 kB entry chunk (223.97 kB gzip). Frozen JS installation failed. Python installation had incompatible test dependencies, and the deleted orchestrator import caused three setup errors. Most probes used mocks rather than real database/browser integration.

The dated JavaScript scan reported 82 advisories: four critical, 18 high, 53 moderate and seven low. This was a dependency-graph result, not proof that every advisory was exploitable. The original [dependency snapshot](dependencies-2026-10-24.json) is retained; the [status ledger](STATUS.md) records later scans separately.

| A11 | Root verification and package-manager pins were incomplete |

Repair order: reproducible installs, ownership/authentication, telemetry/alerts, UI/AI boundaries, then operational and release evidence. The later ledger preserves the distinction between implemented repairs and pending external/manual checks.
